# 退款与退货政策

## 一、适用范围

本政策适用于本平台自营及入驻商家销售的全部实物商品。虚拟商品、定制类商品、已拆封的个人护理用品等特殊品类不适用七天无理由退货，具体以商品详情页标注为准。

## 二、七天无理由退货

用户自签收次日起七日内，在商品完好、不影响二次销售的前提下，可申请无理由退货。

商品完好的判定标准：

1. 商品本身、配件、赠品、说明书齐全，无缺失；
2. 商品未经使用、未经激活、无划痕与污渍；
3. 原包装完整，防伪标识未被撕毁；
4. 发票、保修卡等随附单据齐备。

以下商品不支持七天无理由退货：生鲜食品、个人定制商品、已拆封的贴身衣物与护理用品、软件类虚拟商品、已激活的数码产品。

## 三、退款时效

退款审核通过后，款项按原支付渠道退回：

- 支付宝余额：实时到账；
- 支付宝绑定的银行卡：1 至 3 个工作日；
- 微信支付：1 至 3 个工作日；
- 银行卡直付：3 至 7 个工作日。

具体到账时间以支付机构处理进度为准，平台在审核通过后即发起退款，后续时效不由平台控制。

## 四、退款流程

1. 用户在订单详情页点击"申请退款"，选择退款原因并上传凭证；
2. 商家在 48 小时内审核，超时未处理系统自动同意；
3. 审核通过后，未发货订单直接退款；已发货订单需先寄回商品；
4. 用户填写退货物流单号，商家收货验收后发起退款；
5. 退款完成后订单状态变更为"已退款"。

## 五、运费规则

- 因商品质量问题、错发、漏发导致的退换货，往返运费由商家承担；
- 七天无理由退货，退回运费由用户承担，商家不退还原始订单的发货运费；
- 购买运费险的订单，退货成功后保险公司按保单约定赔付运费。

## 六、质量问题与错发漏发

商品存在质量缺陷、与描述不符、错发漏发等情形，不受七天期限限制，用户可随时申请售后。经核实后，平台支持退货退款、换货、补发三种处理方式，往返运费由商家承担。

## 七、退款状态说明

- 待审核：申请已提交，等待商家处理；
- 已同意：商家同意退款，等待用户寄回或等待退款执行；
- 退款中：退款指令已提交至支付机构；
- 已退款：款项已退回，流程结束；
- 已拒绝：商家驳回申请，用户可补充凭证后重新申请或申请平台介入。
